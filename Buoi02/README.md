# Buổi 2 - Quản lý bài viết
## Đối tượng dữ liệu
Bài viết trong website tin tức của Khoa.
## Chức năng
- Nhập tiêu đề bài viết
- Nhập tác giả
- Chọn chuyên mục
- Hiển thị danh sách bài viết
- Xác định trạng thái bài viết
## Công nghệ
- HTML
- PHP
## Cách chạy
1. Mở XAMPP.
2. Chạy Apache.
